# Screenshots

This folder is intentionally empty.

`Demo.xcodeproj` has never been built or run. The repository was produced in an
environment with no macOS shell (so no `xcodebuild` and no `simctl`) and no permission to
drive Xcode, so there is no Simulator capture to put here.

Rather than fill the folder with a rendered mock-up captioned as a device screenshot, it
stays empty and the README says so. The library itself is a different matter: `swift
build` and `swift test` both pass, 38 tests, 0 failures — that part is genuinely verified.

If you build the demo and want to contribute a real capture, a PR is welcome.
